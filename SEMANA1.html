1. Características de la BD y SGBD

Una base de datos organiza información para que pueda ser almacenada, consultada, actualizada y protegida de manera eficiente.

🔐

Seguridad

Controla quién puede acceder, modificar o administrar la información mediante usuarios, roles y permisos.

🛡️

Integridad

Mantiene los datos correctos y coherentes mediante restricciones, claves y reglas de validación.

👥

Concurrencia

Permite que varios usuarios trabajen con los datos simultáneamente evitando conflictos.

💾

Persistencia

Los datos permanecen almacenados y pueden recuperarse posteriormente.

⚡

Rendimiento

Optimiza las consultas y el acceso a grandes cantidades de información.

🔄

Recuperación

Permite realizar copias de seguridad y recuperar la información ante fallos.

2. Tipos de Bases de Datos

Los diferentes modelos se utilizan dependiendo de la estructura, volumen, velocidad y necesidades de los datos.

📊

Relacionales — SQL

Organizan los datos en tablas formadas por filas y columnas. Utilizan relaciones entre tablas mediante claves.

MySQL PostgreSQL Oracle SQL Server
📄

Documentales — NoSQL

Almacenan información como documentos flexibles, generalmente utilizando estructuras como JSON.

MongoDB CouchDB
🔑

Clave - Valor

Utilizan una clave única asociada a un valor. Son útiles cuando se necesitan consultas rápidas.

Redis DynamoDB
🕸️

Bases de Datos de Grafos

Representan entidades como nodos y sus relaciones como conexiones o aristas.

Neo4j

Característica SQL / Relacional NoSQL
Estructura Tablas, filas y columnas Documentos, clave-valor, grafos, etc.
Esquema Generalmente definido Flexible
Escalabilidad Vertical y también horizontal Frecuentemente horizontal
Uso frecuente Banca, ventas, ERP, facturación Big Data, aplicaciones web y tiempo real

3. Arquitectura de una Base de Datos

La arquitectura de tres niveles ayuda a separar la forma en que los usuarios ven los datos de la forma en que realmente se almacenan.

👤 NIVEL EXTERNO

Vistas de los usuarios y aplicaciones. Cada usuario puede observar solamente la información que necesita.

↓

🧠 NIVEL CONCEPTUAL

Describe la estructura lógica completa de la base de datos: entidades, relaciones, atributos y restricciones.

↓

💽 NIVEL INTERNO

Representa cómo se almacenan físicamente los datos, índices, archivos y estructuras de almacenamiento.

4. Desarrollo tecnológico de las BD

Las bases de datos han evolucionado desde sistemas de archivos hasta plataformas distribuidas y servicios inteligentes en la nube.

1960s · Primeros SGBD

Aparecen sistemas de gestión que permiten administrar grandes volúmenes de información de manera estructurada.

1970s · Modelo Relacional

El modelo relacional transforma la forma de organizar y consultar información mediante tablas y relaciones.

1980s–1990s · SQL y SGBD comerciales

Se consolidan sistemas como Oracle, SQL Server, MySQL y PostgreSQL.

2000s · Web y grandes volúmenes

El crecimiento de Internet exige mayor disponibilidad, rendimiento y escalabilidad.

2010s · NoSQL y sistemas distribuidos

Se expanden bases documentales, clave-valor, columnas y grafos para aplicaciones de gran escala.

Actualidad · Nube + IA + Big Data

Las bases modernas integran servicios cloud, analítica avanzada, datos masivos y tecnologías de IA.
